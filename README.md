# denkenchiku

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository provides open data and resources for Japan's Important Preservation Districts for Groups of Traditional Buildings (伝統的建造物群保存地区).

## Demos

- **[List of Preservation Districts](https://code4fukui.github.io/denkenchiku/)**
  A complete, searchable list of all designated districts in Japan.

- **[Map of Historical Post Towns (宿場町)](https://code4fukui.github.io/denkenchiku/syukubamachi.html)**
  An interactive map showcasing the districts that are historical *shukuba* (post towns).

## Features

- **Up-to-date Data:** The dataset is generated by scraping the latest information from Japan's Agency for Cultural Affairs.
- **Geocoded:** Each location includes a `geo3x3` hash for easy mapping and spatial analysis.
- **AR Ready:** The data includes a link to a USDZ 3D model for the Kumakawa-juku post town, which can be viewed in augmented reality.
- **Automated Processing:** Deno scripts are provided to download and parse the source data into clean CSV files.

## Data

The data is provided in CSV format and is sourced from the [Agency for Cultural Affairs, Japan](https://www.bunka.go.jp/seisaku/bunkazai/shokai/hozonchiku/).

- `denkenchiku.csv`: The complete list of all preservation districts.
- `denkenchiku-syukubamachi.csv`: A subset containing only districts classified as *shukubamachi* (post towns).

Key data fields include district name, prefecture, type, designation date, area, a link to the official PDF, `geo3x3` code, and a `usdzurl` for 3D models where available.

## How to Update the Data

You can regenerate the data files using Deno.

1.  **Download the latest source HTML:**
    ```sh
    deno run -A download.js
    ```

2.  **Process the HTML into CSV files:**
    ```sh
    deno run -A make.js
    ```
